# Security Policy

## Supported versions

The project aims to provide security updates for the latest published minor version.

## Reporting a vulnerability

Please report security issues privately through the GitHub Security Advisory mechanism if available for this repository, or contact the maintainers through the repository's private reporting channel.

Please include:

- a concise description of the issue
- affected version(s)
- reproduction steps if available
- any suggested mitigation

We will investigate and respond as quickly as possible.

## Disclosure policy

We ask that vulnerabilities be reported privately before public disclosure so the maintainers have time to assess, patch, and release a fix safely.
